AI Nakoukavac v0.1

AI-powered video analysis & browsing tool — watch, summarize, and search through raw video footage using Google Gemma 4.

[Remote A100 GPU Server] [Local Machine] video.mp4 ──SCP──> analyze.py nakoukavac-app (Next.js) │ │ ├─ shot detection ├─ Load video.mp4 (local file) ├─ frame extraction ├─ Load .nakoukavac.json ├─ Gemma 4 31B-it ├─ Browse hierarchy ├─ Gladia (audio) ├─ Play segments ├─ embeddings ├─ Search descriptions │ └─ View details └─> analysis.json ──SCP──>

Prerequisites

Remote GPU Server Remote

  • NVIDIA GPU with ≥80 GB VRAM (A100 recommended) for Gemma 4 31B-it
  • Python 3.10+
  • ffmpeg and ffprobe installed
  • SSH access from your local machine
  • Optional: GLADIA_API_KEY env var for audio transcription

Local Machine Local

  • Node.js 20+ and npm
  • A modern web browser (Chrome, Firefox, Edge)
  • The raw video file stored locally

Setup — Remote Server

1

Clone the repository

git clone https://github.com/kereptom/nakoukavac.git
cd nakoukavac/remote
2

Create a Python virtual environment & install dependencies

python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

This installs PyTorch, Transformers, PySceneDetect, sentence-transformers, and other dependencies.

First run will download the Gemma 4 31B-it model (~60 GB) and the embedding model (~600 MB). Ensure you have sufficient disk space and a HuggingFace account with access to the gated Gemma models.
3

Accept the Gemma 4 license

Gemma 4 is a gated model. You need to:

  1. Go to https://huggingface.co/google/gemma-4-31B-it
  2. Accept the license agreement
  3. Log in on the server: huggingface-cli login
4

Optional Set up Gladia API for audio transcription

export GLADIA_API_KEY="your-api-key-here"

Get a key at https://www.gladia.io. Skip this if you only need visual analysis (use --no-audio flag).

Setup — Local Machine

5

Clone the repository

git clone https://github.com/kereptom/nakoukavac.git
cd nakoukavac/app
6

Install dependencies & start dev server

npm install
npm run dev

The app will be available at http://localhost:3000

Usage — Full Workflow

A

Upload video to remote server Local

scp /path/to/my_video.mp4 gpu-server:/data/video/
B

Run the analysis pipeline Remote

ssh gpu-server
cd nakoukavac/remote
source venv/bin/activate

python analyze.py /data/video/my_video.mp4 \
  --output /data/video/my_video.nakoukavac.json \
  --language both

Available flags:

FlagDefaultDescription
--modelgoogle/gemma-4-31B-itHuggingFace model ID
--embedding-modelAlibaba-NLP/gte-multilingual-baseEmbedding model for search
--languagebothOutput language: en, cs, or both
--scene-threshold27.0Shot detection sensitivity (higher = fewer cuts)
--min-scene-len15Minimum shot length in frames
--no-audio—Skip audio transcription (no Gladia needed)
--keep-frames—Keep extracted JPEG frames after processing

Processing time: ~15–30 min for a 45-min video (varies by shot count and GPU).

C

Download the analysis result Local

scp gpu-server:/data/video/my_video.nakoukavac.json ./

The JSON file is typically 1–5 MB (mostly embedding vectors).

D

Open in the browser Local

  1. Make sure the dev server is running: cd nakoukavac/app && npm run dev
  2. Open http://localhost:3000
  3. Drag & drop both files onto the drop zone:
    • Your video file (my_video.mp4)
    • The analysis file (my_video.nakoukavac.json)
  4. Alternatively, use the "Select Video" and "Select JSON" buttons
The browser will load the video and analysis — you can now browse the full hierarchy, play any segment, read AI descriptions, and search through the content.

Quick Test (No GPU Needed)

A sample analysis JSON is included at app/public/sample-analysis.nakoukavac.json. To test the UI without running the GPU pipeline:

  1. Start the app: cd app && npm run dev
  2. Open http://localhost:3000
  3. Load any short video file (the descriptions won't match, but you can test the UI)
  4. Load the sample JSON from app/public/sample-analysis.nakoukavac.json
